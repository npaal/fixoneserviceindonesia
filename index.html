Draf & cadangan

Perubahanmu tersimpan otomatis di browser ini. Pakai cadangan untuk memindahkan ke perangkat lain atau berjaga-jaga bila data browser terhapus.

Publish ke GitHub

Semua perubahan dikirim sebagai satu commit. Vercel otomatis membangun ulang situs, biasanya siap dalam 1 sampai 2 menit.

Cara membuat token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: pilih hanya repo situs ini.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Salin token ke kolom di atas. Token disimpan hanya di browser ini dan tidak ikut ke situs.
